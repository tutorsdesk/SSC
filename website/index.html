Questions

Frequently asked questions

Is Tutor's Desk available for both phone and PC?＋

Yes. Download the Android APK for mobile devices or the Windows installer for 64-bit Windows 10 and 11 computers.

Which Windows download should I choose?＋

The installer is best for most people. The portable ZIP runs without installing: extract the complete ZIP before opening Tutor'sDesk.exe.

Will my papers include a watermark?＋

Watermark behavior follows your active plan. The app always shows the current entitlement before export.

Are these production store releases?＋

These are current preview builds distributed directly through GitHub. Windows may show an Unknown publisher message because the installer is not commercially code-signed.
